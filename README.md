## 🌟 System Overview

**GenMitra** is a fully automated, production-ready AI agent that automates LinkedIn brand presence. It continuously monitors RSS feeds, tech news, Reddit, and Twitter/X, uses Google Gemini to rank viral engagement hooks, writes high-converting posts, schedules them across 5 daily slots, and monitors post performance.

  <img src="https://img.shields.io/badge/🔍_MULTI--SOURCE_TREND_DISCOVERY-0052CC?style=for-the-badge" alt="Trend Discovery">

- 🔍 **Multi-Source Trend Discovery**: Scrapes TechCrunch, OpenAI, MIT Tech Review, HBR, Reddit, and Twitter.
- ✍️ **Gemini 3.5 Copywriter**: Formats pattern-interrupt hooks, short body text, CTA questions, and hashtag clusters.
- ⏰ **Automated APScheduler Daemon**: Publishes across 5 calibrated daily time slots.
- 📊 **Flask Web Control Panel**: Monitor status, preview upcoming posts, and view live JSON logs.

## 🛠️ Tech Stack & Architecture

- **Language**: Python 3.10+
- **LLM Engine**: Google Gemini 3.5 Flash (`google-generativeai`)
- **Scheduler**: APScheduler
- **Web Dashboard**: Flask, Flask-CORS, HTML5/CSS3
- **Deployment**: Render / Heroku / Gunicorn (`Procfile`, `render.yaml`)

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/manoharchalla-in/genmitrasolutionsagent.git
cd genmitrasolutionsagent

# Install dependencies
pip install -r requirements.txt

# Copy environment template & add your keys
cp .env.example .env

# Run full pipeline test immediately
python main.py --run-now

# Launch background scheduler
python main.py
```
